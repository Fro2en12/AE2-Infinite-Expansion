## 📦 内容

### ✦ 万能无限存储元件

| 模式 | 名称 | 说明 |
|------|------|------|
| **Mode 1** | 无限制存储 | 无限容量 + 全 AE 类型，正常存取 |
| **Mode 2** | 自定义无限 | 三种工作模式（阈值/存入无限/臻藏），白名单 + 通用阈值 |
| **Mode 3** | 全类型无限 | 遍历注册表，所有物品+流体存入即无限 |

**特性：**
- 内部使用 `BigInteger` 存储，突破 `Long.MAX_VALUE` 限制
- AE 终端显示上限为 `Long.MAX_VALUE`，真实存储持续累加
- 模式间切换自动刷新、无限物品保留
- 中文拼音搜索 + 分类过滤面板
- JEI 拖拽加入白名单
- **tag / mod 批量无限**：Mode 2 的规则框支持 `tag:minecraft:logs`（整个物品/流体 tag）与 `mod:gtceu`（整个模组），整类物品一键无限
- 分包网络传输，支持数千种类型
- 世界存档级别数据持久化（`WorldSavedData`）

### ✦ 无限合成存储器
- 单个方块提供 **`Long.MAX_VALUE`** 字节合成存储空间
- 合成长整型溢出全周期支持

### ✦ 无限并行处理单元
- 单个方块提供 **`Integer.MAX_VALUE`** 线程
- 搭配 `CraftingCPUClusterMixin` 移除原版 16 线程上限
- 海量并行合成，万亿级配方秒级完成

### ✦ ME接口（无限级）—— 机器供料站 🏭

**一格方块 = 全能供料中枢**，专为「CPU 直灌 → 机器消耗」场景设计：

| 能力 | 说明 |
|------|------|
| **蓄水池** | 内部 BigInteger 无限缓存，CPU 推送多少收多少 |
| **CPU 直灌** | 无条件接收 ScaledPattern N× 缩放后的输入，不阻塞、不回退 |
| **被动补货** | 标记槽标记的物品持续从网络补到补货目标量（虚拟标记，不占存储） |
| **按容量喂出** | 正面贴机器时按机器实际容量分批喂出，溢出自动拒收统计 |
| **主动抽取** | 输入开关开启后按方向/间隔/堆叠配置从机器抽回网络（标记材料自动跳过防回流）。🔄 本轮改为先真实抽取、再按实得量入网 |
| **待入网缓存** 🔄 | 网络满或拒收时，抽到的产物与多余推送料暂留蓄水池并标记待补送，网络一有空间自动补送——不卡机器，也不吞料 |
| **退回网络** 🔄 | 界面里的「⇦退网」按钮：把蓄水池全部材料（未喂出的推送料 + 待入网缓存）一次性插回网络，样板发错或任务放弃后可以收回材料 |
| **双向管道** | 非正面暴露 `IItemHandler` / `IFluidHandler` / Mekanism 气体与化学品能力——管道送入直进网络，抽取走蓄水池 |

**升级卡支持（9 槽全插满）：**

| 卡片 | 效果 |
|------|------|
| 容量卡 ×4 | 样板/标记槽分页：9 → 45 格（每张 +9） |
| 红石卡 | 红石信号控制喂出 |
| 反向卡 | 反转红石行为 |
| 感应卡（AppFlux） | 无线供电 |
| 频道卡（ExtendedAE+） | 无线连接主端（同频段自动配对） |
| 合成卡 | 补货失败且可合成时自动发合成请求，产物直入蓄水池 |

**其他特性：**
- 每接口独立参数：补货目标 / 补货间隔 / 喂出预算（-1 = 跟随全局配置）
- 🔄 主动抽取循环累计上限（`feederExtractLoopLimit`）：同一个 tick 内循环抽取直到达到上限，`0` = 关闭循环、只按配置堆叠量抽一次
- 状态行实时显示：蓄水池容量、喂出速率、拒收、开关状态（点击文字切换）
- GUI 全屏模式自适应，参数置顶 + 分页布局
- 样板管理终端（Pattern Access Terminal）兼容
- 掉落保留全部配置（标记/参数/开关/方向），蓄水池内容不随方块掉落
- 全界面中英双语（lang 驱动）

### ✦ ME接口（无限级）· 线缆面板 📡（🔄 上游 v1.3.0 同步 · 1.21.1 面板形态）

挂在 AE2 线缆上的部件形态：线缆上安装后面板朝所在面伸出喂机器——机器贴着线缆即可供料，不额外占格子。

- **同一套供料逻辑**：蓄水池、CPU 直灌、按容量喂出、待入网缓存与方向/间隔/堆叠参数与方块版对齐
- **同一套界面**：GUI / 菜单 / 开关 / 内存卡与配置卡行为经 `FeederHost` 抽象复用方块版，方块与面板操作一致
- **互相转换**：线缆面板与方块版可无序合成 1:1 互转，布线方式随时改

### ✦ 无限级装配处理器 🧩（🔄 上游 v1.3.0 同步）

集成 CPU 的拓展模块：把「无限级装配处理器·核心」贴进集成 CPU 簇即生效，本身不组成独立合成单元。

| 项 | 说明 |
|------|------|
| **样板槽** | 5×9 每页 × 200 页 = 9000 格，声明「可虚拟结算」的合成样板白名单 |
| **虚拟结算** | 集成 CPU 执行到白名单内的合成样板时，材料直接消耗、产物瞬时注入，不占物理合成队列 |
| **增殖结算** | 自指配方（模板复制 `a+b=2a`）在虚拟结算下按 crafting storage 库存感知批量结算，种子回流滚雪球 |
| **样板管理** | 实现 `PatternContainer`，样板管理终端可直接读写模块的样板槽 |
| **白名单范围** | 按网格共享：模块接入哪个网格，就服务该网格的全部集成 CPU |
| **未激活** | 单独放置（没有集成 CPU 簇）时模块不激活，仅样板槽管理界面可用 |

模块的存储贡献为 0，不干扰集成 CPU 的无限存储语义。

### ✦ 配置存储卡 💾
- **右键**接口 = 复制配置；**Shift+右键** = 粘贴配置
- 复制范围：样板槽 + 升级卡（含 NBT）+ 参数 + 标记 + 缓存目标 + 开关 + 方向
- 与 AE2 内存卡数据格式互通
- 🔄 方块版与线缆面板通用（同一套 `FeederHost` 逻辑）

### ✦ 关键配置项 ⚙️（🔄 上游 v1.3.0 同步）

配置文件 `config/ae2addon-common.toml`（改完热重载生效）：

| 配置项 | 默认 | 说明 |
|------|------|------|
| `feederPowerFeCap` | `100000000`（1 亿） | 感应卡单轮供电 FE 上限。机器的能量槽是 int，单轮上限即机器缺口，设更大也等效 |
| `feederPowerPassesPerTick` | `1` | 感应卡每 tick 供电轮数；N 轮 = 上限 N × 单轮上限 |
| 速度卡倍率 | — | 0 张 = 单轮上限原值；1 张 = 单轮上限 ×16（≤ 21.4 亿）；2 张 = 无上限（每轮灌满机器缺口） |
| `cpuDisplayBytes` | `Long.MAX` | 集成 CPU 在合成终端显示的字节数（真实无限，只是显示值） |
| `cpuDisplayThreads` | `0` | `0` = 拉满（`Integer.MAX_VALUE`）；填具体值则显示该并行数 |
| `cpuStorageText` / `cpuThreadsText` | 空 | 非空时直接覆盖显示文本（如填「无限」「拉满」），留空走数值/∞ 逻辑 |
| `feederExtractLoopLimit` | `1000000` | 主动抽取同 tick 循环累计上限；`0` = 关闭循环 |
| `dispatchBudgetPerTick` | `20000` | 全网格每 tick 成功派发预算；`0` = 不限。防多个巨型订单同 tick 抢占拖垮服务端 |

显示覆盖同时作用于合成确认界面与 CPU 列表。

## 📖 使用指南（ME接口）

1. **样板槽**：放编码样板（定量），CPU 按样板推送时接口无条件收下全部输入进蓄水池
2. **标记槽**：右键/JEI 拖取标记物品（虚拟标记），接口持续从网络补货到目标量；中键点击标记槽可设置该标记的独立缓存目标（支持 K/M/G/MAX）
3. **正面**：对准机器摆放，接口按机器容量分批喂出
4. **开关行**：点击「输入[开/关]」切换主动抽取，「方向[正/后/左/右/上/下]」循环切换抽取方向，「输出[开/关]」切换喂出
5. **参数行**：直接编辑补货目标/间隔/预算后点保存
6. **退回网络**（🔄）：点「⇦退网」把蓄水池全部材料插回网络存储，收不回的（网络满）留在蓄水池
7. **配置卡**：右键复制 → 换接口 Shift+右键粘贴，整站秒部署
